版本：0.18.1-rel。来源：本次聊天中用户逐次提出的要求；状态不把设计、合成测试或缓存人数相等当作真实效果证明。代码路径相对于 QQ 项目根目录。本文件随更新维护，并同步到课程“大作业”目录。

## 范围与验收原则

只处理当前用户有权读取的已导入 QQ 本地记录，不写源 QQ 数据库，不自动发消息。全局 Agent 默认读取当前账号群聊，明确涉及私聊时才开放；用户主动打开的私聊空间仅授权该固定会话。通过受控工具完成任务，修改限软件自有记忆/设定/收藏等，不提供任意SQL。未导入、不可见、缓存缺失或源记录精度不足的内容不得补造。密钥和真实私人内容不进入源码、提交材料、测试夹具或日志。

“已完成”指存在可操作入口及对应验证；“有条件完成”说明依赖真实数据或服务配置；“未完成”保留明确缺口。模型来源编号通过只代表来源及范围有效，不等于语义或人格判断已经真人核实。
