# 0.8.1-rel

上海及所有中转接口按已核实的模型官方价估算，显示价格来源、核验日期和参考计价说明；加入DeepSeek、MiniMax、OpenAI与Claude对应模型，未知名称不猜价。计入缓存读取/写入、DeepSeek北京时段和支持模型的长上下文价。历史无定价记录自动补算，已有费用和真实用量不改写，月费用预算明确为估算预算。
服务额度不足不再反复重试或缩块等待；输出截断、上下文错误与额度类429分别提示，已完成分段可保留。

新增可选“分段压缩后汇总”：先逐段读取，再分层合并为最终目标字数，全部阶段都受预算、容量和限流约束；中断后继续未完成节点。摘要可能遗漏内容，结果保留来源并标明损失。
文字API增加Responses协议；上海DS已验证的指定模型关闭思考，减少思考占满输出额度。原文模式也采用短证据编号；非法引用不收录，最多重读该段一次。限流按服务等待时间恢复，未知限额时缩小本任务输入。

全部七个群AI功能可按次选择关闭、适度或强力消息压缩；字段精简和截短在本地完成。勾选分段汇总后会增加摘要合并的模型调用，可能丢失内容或语境，历史会标注损失并保留原文引用。
输出长度改为自行输入1–20000字的目标；分段汇总模式作用于最终结果，普通模式作用于每段分析或每份草稿，多段合并可能更多，仍受模型输出Token与预算限制。群设置可保存默认压缩、汇总模式和字数，供手动与定时分析使用。

AI 设置增加模型上下文自动建议、TPM、输出额度和推荐读取条数。手动容量测试只发合成消息，支持总用量和条数上限、取消与用量记账；超过推荐条数时弹窗。未知模型和未触及边界的测试会明确标注。
完整请求过大时自动继续分块；配置 TPM 后按安全额度等待，输出截断提示指出具体额度。普通分析不再因无意义的图片收藏索引失败，真正的收藏仍严格校验来源。

修复历史详情打开时的布局闪动，读取失败不再隐藏详情；消息默认从最新到最旧。

群独立角色及 AI 身份回填；每次调用的分页历史卡片；多 QQ 特别关注及群和成员长期记忆。
