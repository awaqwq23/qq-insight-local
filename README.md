# QQ Insight

把本地 QQ 聊天记录整理成可搜索、可提问、可导出的个人工作区。

QQ Insight 是一款 Windows 桌面工具。你可以浏览群聊和私聊，直接向 AI 提问，整理任务、分析表达习惯、生成文件，并逐步积累有来源的本地记忆。

[下载 Windows 便携版](https://github.com/awaqwq23/qq-insight-local/releases/latest) · [查看所有发行版](https://github.com/awaqwq23/qq-insight-local/releases) · [开发与迭代记录](PROMPT.md)

## 可以用来做什么

| 功能 | 用途 |
| --- | --- |
| 本地聊天浏览与搜索 | 按账号查看已导入的群聊、私聊，搜索正文、人物和时间，收藏重要消息 |
| 像网页聊天一样使用 AI | 每个群、私聊和全局空间分别保存多个对话，支持连续追问、修改问题、重新生成和查看旧分支 |
| 群聊总结与任务整理 | 总结近期话题、提取与你有关的任务和截止时间，生成 Markdown 文件 |
| 成员画像与风格 Prompt | 选择一个成员节省费用，或分析范围内所有发言者，归纳语气、近期兴趣、性格倾向和习惯，生成可复用的表达风格提示词 |
| 持续记忆与上下文复用 | 按会话保存概括、成员及消息记忆；已有内容可继续完善，长记录复用有效压缩上下文 |
| 文件与图片处理 | 导出原话问答为 Markdown、发言顺序为 Excel，实际识图后筛选并保存本地表情包 |
| 名单导出 | 导出群列表、历史发言成员或本地成员缓存，分别保留原昵称与群名片 |
| AI 历史记录 | 从左栏汇总查看群聊、私聊和全局 AI 对话，点击回到原会话继续 |

## 下载与运行

1. 打开 [最新发行版](https://github.com/awaqwq23/qq-insight-local/releases/latest)。
2. 在 **Assets** 中下载 `QQ-Insight-版本号-portable.exe`。`Source code` 是源码，不是可直接运行的程序。
3. 双击运行，无需另外安装 Python 或 Node.js。升级时先关闭旧版，再运行新版。
4. 发行版附有 `SHA256.txt`，可以核对下载文件是否完整。

当前发行包适用于 **Windows x64**，普通用户权限运行。升级前可在“设置 → 数据与账号”导出备份；回退旧版本时使用升级前备份。

## 第一次使用

### 1. 导入聊天记录

打开程序后选择 QQ 账号，点击“获取聊天记录”，按提示确认后导入。默认增量更新，只处理新增和发生变化的记录。

自动读取加密的 QQ 数据库需要你另行准备 `qq-win-db-key-master`，放在程序旁的同名目录或 `tools` 目录。该第三方助手不随发行包提供。已有密钥、已解密数据库或本软件备份时，也可以在“设置 → 数据与账号 → 手动导入与数据库备份”选择本地文件导入；读取 QQ 源数据库前先备份。

导入后可以直接浏览、搜索和导出，不配置 AI 也能使用这些本地功能。

### 2. 配置 AI

进入“设置 → 模型接口”，新增文字配置，填写 **Base URL、模型名称和 API Key**，点击“保存并使用”。支持 OpenAI 兼容接口、Anthropic Messages 等协议，按服务商要求选择。

需要筛选表情包或读取图片附件时，另外配置“图片识别”；需要语音转写时配置“语音转写”。在“预算与用量”设置额度并查看调用记录，API 的实际费用以服务商账单为准。

### 3. 开始提问

- **只分析一个群或私聊**：在“消息浏览”打开会话，点击“AI聊天”。直接输入问题，或选择预设 Agent 后修改再发送。
- **查多个群或跨会话找人**：打开左侧“全局 AI Agent”。默认读取群聊，需要私聊时在问题中明确写出。
- **只分析某个成员**：选择“单成员画像（省费用）”，在成员页点击“分析此成员 / 继续完善”。
- **回到以前的对话**：点击左侧“历史记录”，或在聊天标题旁展开“对话”。
- **管理记忆**：打开“记忆与设置”，查看、纠正或忘记会话及成员记忆，也可暂停对应会话的记忆。

可以这样问：

> 帮我整理这个群最近一周需要我做的任务，做成 MD 文件。
>
> 总结这个人在群聊和我私聊中的说话方式，生成一个可复用的风格 Prompt。
>
> 把今天所有私聊里别人问我的问题和我的回答，按原话整理成 MD 文件。
>
> 导出这个群指定时间段的发言顺序，Excel 中只保留人名。
>
> 从群聊缓存中找五张适合回复的可爱表情包，实际看图后保存。

提问时写清楚群、人物、日期或时间范围，更容易得到符合要求的结果。结果可以继续追问、修改，生成的文件可在对话中打开或另存为。

### 4. 导出名单

在“消息浏览 → 其他功能”中导出群列表；选中群后可导出历史发言成员或成员缓存。导出同时保留 **QQ 原昵称** 和 **群名片** 两列。

普通群成员可以尝试导出本地成员缓存，其中可能包含未发言者；缓存不完整时无法保证全员或实时准确。官网导出需要对应账号具备查看名单的权限，历史发言成员也不等于当前全体成员。

## 数据与能力说明

- 原始聊天、历史对话、记忆和配置保存在本机。使用 AI 时，所选消息或附件会发送给你配置的模型服务。
- 软件不写入 QQ 源数据库，不自动发送消息。全局默认只读群聊，私聊需要明确范围；不同账号和会话的记忆分别保存。
- 画像是依据发言作出的暂定归纳。样本不足先保存阶段内容和待补字段，不能保证还原真实性格或完全模仿本人。
- 压缩摘要可能遗漏细节，原话文件会回到源记录生成；图片功能需要本地可读缓存和可用的识图配置。
- 当前主要支持 Windows QQ 本地记录，微信入口尚未接入；现有预设与工具 Agent 不等同于已经实现多角色独立协作。
