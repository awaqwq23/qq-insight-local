# QQ Insight

当前版本：**0.18.1-rel**，Windows x64 便携版，默认普通用户权限。

0.18.0版本真实记录21个场景有通过记录，使用国内MiniMax订阅和DeepSeek交叉测试；包含3000条消息的阶段画像、单成员、记忆、MD/XLSX及五张实际识图保存。画像复核曾有模型分歧，问答完整召回与真人风格尚未证实，见[验收记录](docs/verification.md)。

运行 `release/QQ-Insight-0.18.1-rel-portable.exe`，无需安装 Python 或 Node.js。
修复历史详情打开时的布局闪动，加载失败保留选择；消息默认从最新到最旧。
支持 QQ 本地记录导入、增量更新、搜索、收藏、备份及群 AI 分析。
文字 API 可选 Chat Completions 或 Responses 协议；Responses 等待完整流式结束并记录真实用量，截断结果不会收录。已配置大上下文的模型按容量扩大分块。原文模式完整保留正文，证据采用临时短编号并在本地恢复，减少模型抄错长消息ID导致的失败。
所有接口按已核实的模型官方价格估算，包括上海及中转接口。逐次用量显示输入、输出、缓存和价格来源，自动区分DeepSeek时段及支持模型的长上下文费率；历史未知价格按当前快照补算，有用量缺失的记录仍为未知。费用与月度上限均为参考估算，服务商实际账单可能不同。未核实的模型名称不猜价，价格与假期日历需随发布更新。
旧版分块分析保留“分段压缩后汇总”：先逐段读取并生成带来源的摘要，再分层合并为用户填写的最终字数目标。读取和汇总都受预算、上下文及TPM约束；失败可继续未完成部分。此模式可能丢失细节，报告标明来源和损失，可作为群默认设置供定时分析使用。

在“设置 → 模型接口 → 文字配置 → 高级设置 → 模型容量与读取建议”查看或修改上下文、TPM 和输出额度。选择模型时优先使用接口容量元数据或对应官方快照；未知模型明确标注保守额度。
可展开“手动测试模型最大读取量”，设置消息上限和总测试 Token 上限，测试只发送合成消息并记入用量账本。结果自动保存成功读取下限、停止原因与推荐条数；超过建议条数会弹窗。测试未触及边界时不会把成功量声称为模型最大上下文，限流也不会当作上下文不足。

## AI历史记录与阅读空间

左侧“历史记录”汇总当前账号所有群聊、私聊和全局AI主题，按最近更新时间排列，支持继续加载更早记录。每个主题显示来源、最近问题、时间与状态，点击回到原对话继续；旧版分析打开对应群的具体存档。主题只列一条，旧分支仍可在原对话切换。

聊天时左侧收紧，原来常驻的主题列表收进标题旁“对话”菜单，“＋新对话”可直接使用。正文与输入框采用16px微软雅黑，增加可读行距并减少外部留白，让消息占据主要空间。详情见[历史入口契约](src/contracts/ai-history-v1.md)。本次更新只做本地与合成回归，无收费API调用。

## 群聊、私聊 AI 聊天

打开群聊或私聊，点击“AI聊天”，直接输入问题、追问或修改之前的问题。每个群、私聊分别保存历史，可在各自空间新建独立主题；全局Agent保留跨会话入口。预设Agent只会填入输入框，内容可修改后再发送。主页面保留对话、输入框、预设和附件，“记忆与设置”集中管理辅助内容，旧版表单分析结果保留在存档中。

本地分别维护会话概括、成员与本人画像、消息压缩记忆；私聊也维护本人/对方身份。未发言或证据不足的成员保持未知。每次成功分析按来源完善，画像先复用已核验上下文，必要时回查原话，再完善自动Agent背景；人工Prompt、身份和锁定纠正优先。可选择性查看、纠正、忘记，或暂停整个会话的记忆。

成员画像重点看语气和用词、最近话题提示的可能兴趣、暂定性格倾向和习惯，允许先保存部分内容，未知维度待补。在群聊AI预设选择“范围内全体成员画像”，或“单成员画像（省费用）”后选择成员、点击“分析此成员 / 继续完善”；可修改输入框中的条数或时间再发送。全体是指定范围内有发言的人，包括自己。成功分块立即保存到“记忆与设置 → 成员”，整次分析后续失败仍保留；程序保留的发言节选明确标为待补，不冒充完整人格。规则见[阶段画像契约](src/contracts/ai-v15.md)。

聊天页显示“还有多少条未读取”和实际已压缩区间，支持不连续范围。已分析的消息保存本地摘录与有哈希校验的语义摘要；短材料直接读原文，长材料优先有效上下文、按需压缩未覆盖部分，再完成分析；不清楚的措辞/风格回查原文，数字和顺序用SQL。长正文和引用可能截短，压缩不等于无损保存；原记录变化会重新计为未读。纯聊天、用户补充和失败的压缩步骤不冒充读过记录；成功压缩独立保存，后续任务失败仍可复用。

群聊、私聊和全局均可添加图片、语音及UTF-8文本附件，每轮最多4份、每份8MB；文本最多10万字并分页读取。图片/语音分别需要独立识图/转写配置，会产生API用量；不把附件当成QQ来源证据。目前支持PNG/JPEG/GIF/WebP、WAV/MP3/M4A/OGG、TXT/MD/CSV/JSON/LOG，其他格式请先转换。

全局聊天右上角“我的设置”保存当前账号的称呼、QQ/UID、身份和长期偏好；会话中的身份可单独补充。本人观察按来源会话保留，私聊观察不进入只读群聊的问题。自己的发言在聊天记录右侧；如果旧库缺少可靠方向，可填写本人的QQ/UID辅助识别。

AI可以直接回答，按需检索记录、修改软件自有记忆/Agent设定和收藏、生成MD/XLSX或保存图片。只有当前用户明确要求修改时，修改工具才可执行；QQ源库始终只读，模型没有任意SQL、命令或文件路径权限。详情见[会话聊天契约](src/contracts/ai-v12.md)。

## API 连接设置

“设置 → 模型接口”左侧选择文字配置、图片识别或语音转写，右侧一次编辑一项。正在编辑的文字配置不一定已启用，左侧“使用中”标记当前配置，保存并使用后生效。已存API Key留空即可保留，显示按钮只显示本次输入。

协议、模型容量、TPM与读取量测试收在“高级设置”；模型列表可搜索。“预算与用量”和“数据与账号”单独分组，原来的导入、备份、分页与账号设置在后者。能力和容量测试仍需手动启动，会产生API用量。

## 全局 AI Agent 与记忆

左侧“全局 AI Agent”可新建多个独立对话，连续提问或修改要求；每个对话的已发送问答自动保存在本机，支持重命名。修改旧问题/重新生成时创建新分支，原回复和文件仍可查看，费用保留。不同对话不混用问答上下文；长对话完整保存，本轮容量不足时仅发送部分历史并可回读。未发送草稿仅在当前窗口切换间暂存。直接输入问题，不用先选业务模板。默认读取当前账号群聊；需要私聊请明确写“群聊和我私聊”或“只看私聊”。支持近期工作任务生成真正 Markdown、指定时段发言顺序生成只有人名的 Excel、人物表达场景比较、今日重点及实际识图后保存表情包。任务历史可打开或另存文件，失败任务可删除；需先导入相应记录和配置可用模型，图片需本地缓存及独立识图配置。

成功分析更新来源会话事实、暂定评价和成员观察，支持更正锁定；不同群和私聊的综合推断不会通过切分引用混进单群记忆。旧摘要核对来源哈希后优先使用，再结合新消息；精确数字和顺序用SQL，原话和风格不清楚时定向回源。压缩可能遗漏细节，节省量显示为材料字节，不冒充计费Token。全局普通任务最多32次、图片筛选最多64次任务决策，压缩和识图另外计量且共同受预算约束，预算、证据及失败费用均保留。

全部需求及完成对照见[需求文档](docs/requirements.md)，工具边界见[契约](src/contracts/ai-v10.md)，多对话与修改规则见[对话契约](src/contracts/ai-v11.md)。三角色多轮核查仍未实现；当前是可用的工具Agent与后续协作基础。

## 名单导出

消息浏览右上角的“其他功能”集中提供名单导出、记忆设置和对话记录；主界面仅保留“AI聊天”和“其他功能”两个操作入口。未选群、私聊及全账号范围也可从这里导出当前账号的群列表，仅在选中群时提供成员导出。

普通群成员请选择“其他功能 → 导出成员缓存”。先更新QQ记录，软件从群资料库的独立成员缓存读取，包括未发言者；保留原昵称与群名片。保存前核对缓存人数和群资料人数，不一致或未知会明确提示，数量相同也不保证实时完整。缺失时可尝试在QQ打开完整成员列表并滚动加载，退出QQ后再更新；是否补齐取决于实际缓存。仅导入聊天库或旧备份不能恢复完整成员缓存。

打开群聊后可选择“其他功能 → 导出全体成员（官网）”：在独立的 QQ 群官网窗口登录当前账号，程序读取包括未发言者在内的成员列表，核对所有分页和人数后再选择 CSV 保存位置。账号不一致、权限不足、分页缺失或人数变化时停止，关闭官网窗口可取消。登录会话临时使用，结束后清理；不发消息，不修改群资料，不调用模型。

在“其他功能”中选择“导出群列表”，或打开一个群后选择“其他功能 → 导出发言成员”。CSV 同时保留 QQ 原昵称与群名片（群内备注）两列，缺失值留空，不用私人备注或合并显示名替代。群列表同样分别输出原群名和群备注。

成员范围仅为本地已导入聊天中的发言者，可能含已退群成员，不包含从未发言者，也不代表实时完整名单。名称取最近非空缓存；旧数据请先更新或重新导入 QQ 记录以补齐双名称。导出不覆盖已有文件，不调用模型。

## 使用安全

自动取钥需要用户已有的 qq-win-db-key-master，放入 tools 或便携程序旁，也可用 QQ_INSIGHT_KEY_HELPER 指定脚本。
该助手遵守原许可证，不复制进便携包或上传仓库。操作前备份源记录，只处理获授权的数据。
应用不写源 QQ 数据库；整理项目不删除 Windows 用户应用数据目录中的已导入记录、API 设置。
AI 操作将选定消息发送至用户配置的模型服务，请检查授权、消息范围和预算。

## 人物风格与长期记忆（0.12.0）

在会话聊天中选“人物风格”预设并写明人物，或在全局Agent明确要求跨群/私聊风格分析。旧版“跨群人物风格 / Prompt”仍在分析存档中保留。先导入相关群历史；选择条数/时间范围后开始，最终报告中的“复制风格 Prompt”可交给其他AI。它归纳可观察的表达习惯和暂定偏好，不能保证还原真实性格。此功能使用分段汇总，额外调用同样进入预算和账本。

所有输入使用分钟时间、日期字典及人物短编号。默认关闭有损压缩时正文与引用完整保留；需要进一步减少输入时再选适度/强力，核实其损失提示。不会按名字相似合并身份。

成功分析后，已读发言者的来源和有证据的画像片段保存到来源群长期记忆；后续操作会结合相关片段，用户更正优先。样本不足就保留“尚无稳定画像”，不会为了人人有性格标签而编造。历史页可刷新记忆库、更正并锁定、忘记某条或解除暂停。失败页显示已完成条数与失败分块大小，并可删除失败历史；已合入结果和费用账本保留。

多个功能共享调度器，目前尚不是“三角色、多轮核查与裁决”的协作系统。结课平台设计与待补实测项见课程“大作业”目录；不能把功能数量当作已完成多Agent协作的证据。

升级前可在“设置 → 数据与账号”导出数据库备份。新版可导入旧版备份；历史程序不保证能写入新版对话结构，回退时请使用升级前的备份。

## 0.16 修复与上下文流程

表情包候选按近期优先，只返回本机可读取且本次尚未保存的图片；跳过缺图并可继续分页，实际识图后保存、去重。指定保存数量未满足时显示失败及实际数量，已保存文件保留。缓存索引会刷新，不需因一张缺失图片手动下载全部候选。

群聊、私聊、全局及旧版分析入口均先准备通用压缩上下文，再执行具体问题；换预设或目标可共用来源摘要，只压缩新增/变化的记录。回源核实后再次压缩可以完善上下文。成功压缩与最终任务独立保存，受账号/会话/暂停开关/来源哈希约束。原记录旁显示“已压缩”，任务过程显示复用及新增压缩条数。

无效人物观察单独跳过并说明，有效报告和其他成员保留。本人来源用于避免误归因，成员名册仍包括本人、发言者和缓存内未发言者；缺证据保持未知。当前压缩与画像属于模型归纳，可能遗漏细节；旧版存档对摘要遗漏只标待核实，聊天Agent可用工具定向回查。契约见[ai-v13](src/contracts/ai-v13.md)。

## 0.17 连续任务、批量私聊与原话文件

“继续”“今天所有的”等简短补充会保留当前分支的原始任务和用户补充。问题已经明确时，软件按已知范围继续执行；今日全部私聊文件任务会先批量读取当日活跃记录，历史联系人多不再成为逐个排查或反复确认的理由。

短材料（规范化记录材料约16KB UTF-8及以下，实际读取页仍受模型容量约束）直接提供原文，不额外调用压缩模型。长材料按需复用/压缩，原话任务可用摘要定位，但文件正文只能由受控工具从原记录直接写入。工具保留多条回答、换行、标点、空格与表情，并在保存前核验来源。所有任务仍受预算、32次决策和100个工具事件限制；超过限制保留实际进度并显示未完成。

消息与范围统一显示“已处理”，包含原文读取和摘要，不代表每条调用了压缩模型；详细过程区分原文条数、复用和额外压缩。明确要求文件且已读到相关范围时，不能只回答“确认后我再做”；原话任务不能用普通Markdown工具手抄，范围不全不能标完成。契约见[ai-v14](src/contracts/ai-v14.md)。

## 0.17.1 弹窗逐级返回

打开弹窗后，点击窗口外的空白区域即可返回上一层；多层窗口只退一层，点击内容或拖动越过边界不会关闭。“会话设置 → 全局我的设置”支持返回上级，并保留上级未保存的输入；关闭按钮和Esc遵循同样层级。直接离开账号/会话时清理整个旧弹窗。读取确认窗口沿用原取消流程，写入阶段不可取消时不会被背景点击关闭；背景返回不会自动保存或批准操作。

## 0.17.2 长报告输出额度

群画像等长报告推荐每段65536输出Token，不要求每次用完；实际取AI预算输出、模型侧输出和已知接口上限的较小值，输入与输出共同受上下文约束。已保存的小值不会因升级自动改写，可分别调整两处。软件输入允许512–1000000，100万只是配置校验范围，不代表模型能力；未知模型按上下文四分之一且最多65536作为初始建议。DeepSeek官方端点的deepseek-flash/v4-pro上限核验为393216，普通转发地址不冒用官方能力。大于8192的请求最多等待30分钟，仍可取消；截断保持失败状态并保留账本，不收录残缺结果。压缩步骤最多16384，不要求生成完整画像。

## 0.17.3 输出修改生效修复
