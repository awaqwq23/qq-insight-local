# 群角色、调用历史与长期记忆契约（0.5.0-rel）

- “我的角色”只存在于群聊设置；`group.get/save` 按 `conversation_id` 隔离，不再回退到全局角色。
- `identity` 是可手动触发、不可定时的群 AI 功能。它只依据本群证据推断角色；证据充分时将角色回填到当前群设置，结果和普通分析一样进入历史。
- `ai.history` 支持 `job_page/job_page_size` 与 `item_page/item_page_size`。每次分析请求都有独立任务记录，包括缓存复用和空范围；任务摘要公开创建时间、耗时、消息范围、消息数和分块数。
- 完成的分析自动把群级摘要、结果条目以及特别关心的逐人结果写入 `ai_memories`。启用本群记忆时，后续不同功能读取相关群级和成员级记忆，并以新结果或用户更正继续更新。
- `watch_people` 接受英文/中文逗号、分号、顿号、空格和换行，保序去重；每个 QQ/UID 独立选取消息、分块、校验证据和报告覆盖状态。
- 备份恢复携带 `ai_memories`，并重新校验其中每个证据仍属于原群。
