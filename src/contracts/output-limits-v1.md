# 长报告输出额度（0.17.2）

单段最大输出是每次模型回复的Token上限，不是累计预算，也不是要求模型写满。群画像/长报告推荐65536；实际值由预算输出、模型输出、已知接口上限和总上下文共同约束。输入记录多不代表必须产生同样多的输出，成员很多或报告很长时仍应分段。

- 移除旧16384配置硬上限。预算/模型/核心配置校验范围512–1000000；100万仅为软件配置边界，不代表API能力。账本仍按输入估计＋本次最大输出预占，成功按真实用量结算，未知用量保留；不能为容纳大输出绕过总预算。
- 新预算默认输出65536；模型没有保存值时建议min(65536,context/4)，未知32K上下文初始8192。已保存4096/16384等人工值升级后保持不变；当前用户明确授权的本机配置调整另行记录，不做所有用户的静默迁移。
- DeepSeek官方端点api.deepseek.com的deepseek-flash/deepseek-v4-pro，最大输出核验393216，支持65536或131072等较大设置。其他端点/别名不继承官方上限。来源：[官方Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)，核验2026-10-25。
- 接口元数据的max_output_tokens、max_completion_tokens及top_provider.max_completion_tokens可用于输出上限，保存到output_limit_tokens；数值必须合法。设置页显示当前模型和预算共同决定的已保存有效额度。核心允许较大模型描述并再次核验数值及上下文。
- 输入、历史、工具材料与最大输出共同占用上下文；容量不足会分段或报错，不保证任意长材料一次完成。输出变大也增加预算预占；不能把配置上限当本轮必付用量。
- 请求输出超过8192时默认最多等待30分钟，较小请求2分钟；调用者显式传入时限仍优先。保持取消、超时与未知用量账本。超时不等于Token截断。
- 压缩步骤单次最多16384，最终报告推荐65536；短记录不额外压缩。finish_reason=length/max_tokens或Responses不完整终态仍失败，不保存残缺JSON，不无限重复同一请求。
- 没有新增真实模型长输出测试；65536参数、长合成响应、等待时限、协议和预算由合成回归验证。第三方转发限制及实际超长语义质量仍须实际服务核实。
