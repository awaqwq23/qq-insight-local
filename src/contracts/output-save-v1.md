# 单段输出修改与生效（0.17.3）

预算页与模型页的单段输出是同一用户偏好。修改一处并保存时，主进程output-settings通过同一队列协调两处持久化；模型页保存仍启用该配置，并同步全局预算输出。原来的ai.budget.save和settings:save入口保持，无新增模型工具权限。

- 容量查询核对请求版本、编辑版本及所属模型。手动输入优先；保存直接读取当前表单，不等待旧查询回填。查询/旧保存回复不得覆盖新的草稿，未提交部分保持未保存标记。
- 保存先校验512–1000000及已知接口/上下文能力上限，超过上限明确拒绝。保存预算成功后才持久化模型；模型保存失败恢复内存并尝试恢复本次更改的预算字段。回滚失败会明确报告，要求重新读取，而非声称成功。该机制处理运行错误，不宣称跨文件断电事务。
- 同步只改当前模型输出偏好，保留加密密钥、其他配置及累计账本。未配置文字模型时仅保存预算，状态说明需要有效模型。
- 已发送请求及预占额度不能中途改写。后续旧分析分块和全局Agent请求读取新预算，按output_limit_tokens能力与总上下文约束；旧没有能力字段的模型描述回退原output_tokens，继续旧任务时可更新模型描述。
- UI已保存回执携带公开model_output元数据，更新关联模型显示；不返回密钥。主进程两种保存共用队列防止交错。实际输出仍可能因模型提前结束而少于上限；服务拒绝/超时/截断保持失败及用量记录。

合成验证：131072不会被晚到8192覆盖；保存中改为196608保留新草稿；65536↔131072双向保存、重启、预算失败、磁盘失败及回滚失败、队列、加密密钥保留；运行中下一分块/Agent请求使用131072。实际main/preload/core经原生IPC核对两处保存值，未调用模型API。
