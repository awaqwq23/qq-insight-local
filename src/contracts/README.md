# 当前接口说明

- history-v1.md：消息历史、分页与账号范围。
- import-v1.md：增量导入与资料更新。
- transfer-v1.md：手动导入和备份。
- workspace-v2.md：收藏、上下文与群设置。
- ai-v3.md：当前群 AI、调用历史与长期记忆；继承字段参见 ai-v2.md。

入口在 src/core/local_assistant/service.py，配套桌面受限 IPC。修改接口同步消费者与测试。

- roster-v1.md：群列表与群发言成员的双名称 CSV 导出、范围与旧数据兼容。

- roster-v2.md：用户授权的QQ官网全体成员导出，登录隔离、只读请求与分页完整性。

- roster-v3.md：客户端独立成员缓存、普通成员入口、人数对照和备份兼容。

- ai-v9.md：跨群指定人物风格 Prompt、分钟与编号输入、成员画像库和保留费用的失败删除。

- ai-v10.md：来源群记忆与评价、哈希校验摘要复用、全局工具Agent和受控文件/图片输出。

- settings-v1.md：API设置分栏、分类、密钥遮罩、配置启用与迟到响应规则。

- ai-v11.md：全局Agent多对话、连续上下文、修改分支、回读、迁移及备份规则。

- ai-v12.md：群/私聊独立聊天、三类记忆、压缩覆盖、Agent背景更新、全局本人设置及多模态附件。
- ai-v13.md：统一先复用、增量压缩、再执行任务，独立保存压缩痕迹、人物观察容错与图片可用性/数量校验。
- ai-v14.md：连续补充保留原始任务、批量私聊检索、短原文/长按需压缩、逐字原文文件与完成条件。

- [弹窗与逐级返回](ui-overlays-v1.md)：0.17.1界面行为，无RPC/数据库格式变更。

- [长报告输出额度](output-limits-v1.md)：0.17.2推荐65536输出、接口边界、预算预占和等待时限。

- [输出修改与保存](output-save-v1.md)：0.17.3联动、回滚、异步防覆盖及后续请求生效。

- [成员阶段画像与任务修复](ai-v15.md)：0.18单人/全体画像、逐块保存、跨群风格工具、上下文及图片真实失败修复。

- [AI历史入口与聊天布局](ai-history-v1.md)：0.18.1各来源主题汇总、原对话跳转、分页及阅读空间。
