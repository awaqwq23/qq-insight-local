# API 设置界面

0.13.1-rel。仅调整桌面呈现与选择流程，沿用现有 settings、模型发现、容量、媒体和预算接口；不迁移用户设置、不读取其他软件的密钥。

- 设置分为“模型接口”“预算与用量”“数据与账号”，一次只显示一个分类；原有分页、手动导入、备份和账号设置均在“数据与账号”。
- 模型接口左侧展示文字配置、图片识别和语音转写；右侧仅显示正在编辑的一项。文字配置中“使用中”代表已保存的 activeModelProfileId，“选中编辑”不直接改变它，点击“保存并使用”才启用。
- 常用字段为名称、接口类型、地址、模型和密钥；协议、容量、TPM、读取量探测放入默认折叠的“高级设置”。原有能力测试保留，仍会产生模型用量。
- 已存密钥不回显，空值保存继续使用旧密钥。显示按钮仅控制本次输入；切换分类或接口、保存后恢复遮罩。密钥不进入页面摘要、日志或截图样本。
- 未保存的文字配置在切换到另一个文字配置/新增时提醒；仅切换能力页或设置分类保留表单内容。读取模型响应与发起时的配置、地址、接口类型、密钥匹配后才呈现，迟到结果不会覆盖另一配置。
- 模型列表支持不区分大小写搜索与原有分页。媒体配置独立保存，不随文字配置切换；“复制正在使用的文字接口”明确取当前启用配置，而非任意编辑草稿。

参考：[CC Switch 官方项目](https://github.com/farion1231/cc-switch)的配置集中管理与切换思路；本界面自行实现，无新增依赖。合成界面验收见 tests/renderer-settings.test.js，含1200和1540窗口宽度、配置状态、空密钥、遮罩、未保存提醒、搜索和迟到响应；原有媒体、预算、容量及导入验收同步保留。
