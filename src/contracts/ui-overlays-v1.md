# 弹窗逐级返回（0.17.1）

仅更改Electron界面行为，无RPC、权限、模型调用或数据库格式变更。

- 记忆/本人设置与读取量提醒采用原生模态dialog，closedby=any通过cancel流程处理背景。真实打开顺序决定最上层，与DOM排列无关；背景操作不传到底层按钮。一次点击仅返回一层。
- 会话Agent设置打开全局本人设置时，保存上级表单的输入、勾选、滚动位置及所属账号/会话键；背景、关闭按钮及Esc返回原会话设置，恢复未保存草稿和焦点，不自动保存。根层关闭返回原页面。
- 全局本人设置从全局入口直接打开时没有会话父页。切换账号/会话或跳转原消息时使用完整关闭，清除父页及取消迟到响应，不能恢复其他账号的表单。
- 读取量提醒背景取消解析为false，不会同意继续分析。读取记录的自定义遮罩要求按下和抬起都位于遮罩，复用原取消按钮。正在取消或写入不可取消时，禁用状态优先，不强制关窗或中断写入。
- 弹窗内容点击、从内容拖到背景或从背景拖到内容均不关闭。关闭未保存的当前层等同原关闭/取消按钮；上级草稿仅暂存在当前窗口，不承诺跨重启保存。
- 系统文件选择器、独立QQ官网登录窗口沿用系统窗口行为，本规则适用于软件内弹窗。

验证：tests/renderer-overlays.test.js使用当前Electron渲染与真实鼠标输入，覆盖父页草稿/焦点、双向拖动、打开顺序、Esc、范围清理及不可取消写入。全部使用合成界面，不访问实际QQ记录或模型API。
