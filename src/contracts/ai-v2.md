# AI 计费、特别关心与媒体模型契约（0.4.0-rel）

本次跨 M01/M02/M05/M06/M09/M10/M11：请求账本、官方定价快照、逐人覆盖、独立媒体 API、能力筛选/测试必须同步，保留旧数据库及设置。

- 每个真实网络尝试先原子预占预算，再结算输入/输出/缓存 Token、音频秒数、模型、币种、单价、官方来源和日期。失败/取消/未知用量保留记录；缓存命中记零增量调用，不把预占当成实际用量。按秒计费且未返回 Token 时显示“未返回”。
- 官方价匹配供应商域名、地域、完整模型 ID；同名第三方模型不套用原厂价格。费用为官方原价估算，不含免费额度、折扣和合同差异。历史单价冻结，不随后续价格改变重算。未知定价明确显示未知。
- watch_people 接受逗号、中文逗号、空格、换行、分号、顿号，保序去重。特别关心按每个标识独立分块和证据校验，每人显示已分析/部分完成/当前范围无消息，不能只由模型自行挑选第一个。
- settings.mediaProfiles.vision/speech 独立供应商、Base URL、模型、密钥及协议；原文字配置不被覆盖。凭据仅主进程可用。
- model:discover 保留 models 数组，新增 capability 标识；官方已知族/接口元数据用于候选筛选，未测试不宣称可用。model:test 使用软件内置合成图片/语音检验，真实调用仍走预算和账本。
- 图像描述先调用独立识图配置，再作为标注来源的材料供文字模型分析；语音文件可用独立接口转写和测试。原 QQ 私有语音编码未解码时明确不可用。
- ai.usage.list 为可读分页接口；ai.call.reserve/settle、ai.media.save 等只供主进程调用。

0.4.2 预算修复：ai.budget.get/save 返回各字段 limits（min/max/label）；无效保存不部分写入，返回具体字段与范围。BUDGET_EXCEEDED 返回所有阻断维度及 used/limit/remaining/required，并在消息中列出预估输入与最大输出。界面显示已保存状态，支持三项 Token 上限一键设为合法最高值并保存。无图片分块不追加图片描述预占；未知用量继续保守预占，不清零真实用量或自动关闭预算。
